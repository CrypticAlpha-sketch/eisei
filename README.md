# 第二種衛生管理者 ○×問題集（PWA）

スマホの縦画面で使う○×問題集です。ホーム画面に追加すると、アプリのように全画面で開けて、オフラインでも使えます。

## 中身

すべてのファイルが同じ階層に入っています。

- `index.html` … アプリ本体（問題249問を含む）
- `manifest.webmanifest` … アプリ名・アイコン・縦画面固定などの設定
- `sw.js` … オフラインで使うためのサービスワーカー
- `icon-192.png`、`icon-512.png`、`icon-maskable-512.png`、`apple-touch-icon.png` … アプリアイコン

## 公開のしかた

PWAとしてインストールするには、このフォルダを **HTTPS のサイト**に置く必要があります。無料でできる方法を2つ紹介します。

**Netlify Drop（いちばん簡単）**
1. zip を展開し、中のファイルを1つのフォルダにまとめる
2. ブラウザで app.netlify.com/drop を開く
3. そのフォルダをドラッグ＆ドロップする
4. 表示された URL をスマホで開く

**GitHub Pages**
1. GitHub で新しいリポジトリを作り、ファイルをすべてリポジトリの直下にアップロードする
2. リポジトリの Settings → Pages で、公開するブランチを選ぶ
3. 表示された URL をスマホで開く

## スマホへのインストール

- **iPhone（Safari）**：共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**：右上のメニュー → 「アプリをインストール」または「ホーム画面に追加」

## 学習記録について

学習記録は、その端末のブラウザ内に保存されます。claude.ai 上で使う場合の記録とは別になります。

## 問題を更新したとき

`index.html` を書き換えたら、`sw.js` の先頭にある `CACHE` の値（例：`eisei2-ox-v2` → `eisei2-ox-v3`）も変えてから公開し直してください。インストール済みのアプリに新しい版が届きます。
